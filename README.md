FinScope

A full-stack stock tracking web application built with **React**, **ASP.NET** and **TypeScript**.  
This project allows users to view stock data, manage stock records, and interact with related comments through a responsive frontend and RESTful backend.

## Features

- View a list of stocks
- Get stock details by id
- Create, update, and delete stock records
- Add and manage comments for stocks
- Pagination, sorting, and filtering support
- Input validation on backend requests
- REST API with Swagger documentation
- Clean frontend and backend separation
